⚠️ El Problema Inicial

Los municipios y refugios enfrentaban un descontrol en el censo de animales urbanos, registros de vacunación en papel que se extraviaban con facilidad, demoras de hasta 3 semanas para coordinar adopciones y falta de trazabilidad en casos de mordeduras o emergencias sanitarias.

💡 La Solución Desarrollada por Bari Code

Diseñamos y construimos una plataforma modular compuesta por: (1) Aplicación web para gestión municipal con dashboards de zoonosis; (2) Pasaporte Sanitario Digital mediante código QR en chapitas identificatorias; (3) Módulo ciudadano para reporte geolocalizado de animales perdidos; (4) Sistema de match para adopciones responsables.
